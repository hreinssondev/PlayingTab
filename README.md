# PlayingTab

Jump to the Safari tab that’s playing.

Press **⌥⌘P** in Safari to go straight to the tab playing audio or video. Press it again to cycle through other playing tabs. If nothing is playing, it returns to the tab that played last.

## Getting started

1. Open PlayingTab once.
2. In Safari, choose Settings › Extensions and turn on PlayingTab.
3. Allow it on all websites, then reload any tabs that were already open.
